All eight ideas have shipped, and their GitHub issues #1 to #8 are closed.

1. Extract and save images:
Done in 3e08d84, issue #1.
You could add functionality to extract all image URLs from the page using a selector like img and save references to them.

2. Extract meta tags:
Done in 05c34fa, issue #2.
Add support for extracting meta information like description, keywords, and other metadata from the page.

3. Add page size and load time metrics:
Done in 8cea1f3, issue #3.
Track how long it takes to fetch and process each page, as well as the size of the content.

4. Implement filtering options:
Done in b1c6dc4, issue #4.
Allow users to filter the results based on keywords, link patterns, or specific elements.

5. Add crawling capabilities:
Done in e7cf53a, issue #5.
Develop the ability to follow links on the page to crawl through a site to a specified depth.

6. Add more output formats:
Done in e595f96, issue #6.
Support formats like CSV or XML for better integration with other tools.

7. Add screenshots:
Done in b98a525, issue #7, using the Chrome binary in headless mode rather than a crate.
Integrate with a tool like Headless Chrome to capture screenshots of pages.

8. Add concurrency:
Done in a9d66c7, issue #8.
Enable scraping multiple pages concurrently for better performance.
